# План обновления Arcada Planner

Статус: черновик, ожидает подтверждения открытых вопросов (см. в конце).

Порядок работы — по этапам, с проверкой результата после каждого:
**0–1 (баги) → 2–3 (геометрия, внутренние длины) → 4 (линейка) → 5 (подписи) → 6 (зазоры) → 7 (финал)**.

- [ ] Корректный расчёт для T-стыков, стыков под углом, внутренних перегородок.
- [ ] Во время рисования — живая длина над пунктирным превью; внутренняя длина пересчитывается сразу после образования угла.
- [ ] Переключатель режима подписей: **«Внутренние»** (по умолчанию) / **«Обе стороны»** / **«По осям»**.

- [ ] Привязка концов к узлам, граням стен, углам мебели.
- [ ] Shift — строго по горизонтали / вертикали / 45°.
- [ ] Измерение остаётся на плане как размерная линия: сохраняется в файл, выводится на печать, удаляется ластиком, концы можно перетаскивать.


## Этап 5. Подписи объектов и свои тексты

**Подписи мебели**
- [ ] Поле «Подпись» в панели выбранного объекта (`FurnitureItem.label?: string`).
- [ ] Текст рисуется по центру предмета и всегда читается горизонтально, даже если предмет повёрнут.
- [ ] Глобальная опция «Показывать названия из каталога».

**Инструмент «Текст» (T)**
- [ ] Клик по плану ставит надпись, редактирование прямо на месте.
- [ ] В панели: размер, поворот, жирность, цвет.
- [ ] Перетаскивание, копирование (Ctrl+C/V), удаление, undo.

Модель данных:
```ts

```

## Открытые вопросы (выбрано по умолчанию)

1. **Внутренняя длина** — показывается только со стороны помещения; снаружи наружных стен подписей нет. *Альтернатива:* длины с обеих сторон.
2. **Линейка** — измерения остаются на плане. *Альтернатива:* временная, исчезает после следующего клика.
3. **Зазоры** — только у выбранного / перетаскиваемого предмета. *Альтернатива:* у всех сразу (план станет перегруженным).
4. **Язык интерфейса** — сейчас английский. Перевести на русский или оставить?
