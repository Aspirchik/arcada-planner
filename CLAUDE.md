# Правила проекта Arcada Planner

## 1. Журнал изменений — обязательно

**Каждое изменение проекта записывается в [CHANGELOG.md](CHANGELOG.md).** Изменение без записи считается незавершённым.

### Формат записи

```markdown
## № N — ГГГГ-ММ-ДД

### Добавлено
- Что появилось нового.

### Изменено
- Что работает иначе, чем раньше.

### Исправлено
- Какой баг исправлен (кратко: симптом → причина).

### Удалено
- Что убрано.
```

- **N — порядковый номер записи:** 1, 2, 3 и так далее. Каждая новая запись получает номер на единицу больше последнего. Номера не пропускаются и не используются повторно.
- Дата — день внесения изменения, формат `ГГГГ-ММ-ДД`.
- Новые записи добавляются **сверху**, под заголовком файла.
- Указываются только непустые разделы.
- Каждый пункт — одна строка, понятная без чтения кода. При необходимости в конце пункта указывается файл: `(src/store.ts)`.
- Одна запись — одна логически завершённая порция работы (например, один этап или подэтап из [PLAN.md](PLAN.md)). Несколько мелких правок, сделанных вместе, можно объединить в одну запись.
- Если меняется структура сохраняемых данных, в записи это указывается явно, вместе с новым значением поля `version` формата файла `.arcada` (`save()` в `src/store.ts`).

## 2. План работ

- Текущий план — [PLAN.md](PLAN.md). После выполнения пункта отметить его `[x]` и указать номер записи журнала: `- [x] ... (№3)`.

## 3. Перед завершением любого изменения

1. `npm run build` проходит без ошибок TypeScript.
2. Тесты проходят (`npm run test`, после подключения vitest).
3. Добавлена запись в CHANGELOG.md со следующим порядковым номером и датой.
4. При изменении поведения обновлены справка в приложении (`src/ui/Toolbar.tsx`), `README.md` и при необходимости `ARCHITECTURE.md`.

## 4. Соглашения по коду

- Всё состояние хранится в Zustand-сторе `src/store.ts`. Изменения этажа проходят через `upFloor()`, чтобы работал undo.
- Konva-фигуры не слушают события (`listening={false}`). Попадание по объектам определяется вручную геометрией.
- Координаты мира: `METER = 100`, то есть 1 единица = 1 см.
- Геометрию (расчёты, без React) выносить в `src/geometry/` и покрывать тестами.
- Новые поля сохраняемых данных должны быть необязательными или заполняться при загрузке, чтобы старые файлы открывались.
